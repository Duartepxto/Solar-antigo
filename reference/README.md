# Orbit reference implementation

This is a separate, hand-built implementation based on the user-provided `OpenMausBot Orbit.html` design export. It does not replace the Jarvis prototype at the repository root.

Open `http://127.0.0.1:4173/reference/index.html` while the repository's local server is running.

Implemented in this version: animated canvas team map, eleven original bots and three teams, cross-team channel, camera zoom and pan, draggable bot/team positions, bot-to-bot links, focused bot chats, inline demo approvals, capability panels, team and owner panels, command search, activity digest, and attention list.

The conversations, account states, runs, costs, and approvals use sample data from the design. This page does not connect to an AI model, email, calendar, GitHub, or the OpenMausBot runtime. Settings shown here are design states only.
