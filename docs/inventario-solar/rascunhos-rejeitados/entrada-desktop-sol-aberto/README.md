# Rascunho rejeitado — entrada desktop

O utilizador rejeitou a composição e o logo em 10 de outubro de 2026 e pediu pesquisa online antes da próxima aplicação visual. Estes ficheiros preservam o rascunho para análise; não pertencem ao build nem constituem uma direção aprovada.

`rascunho.patch` regista as alterações visuais aos ficheiros existentes. O frame, CSS e símbolo foram retirados de `orbit-app/src`. A composição anterior foi reposta temporariamente, enquanto se estuda uma substituição própria do Solar. A reposição não aprova a composição herdada.

A correção de preservação do nome ao regressar ao primeiro passo e os atributos de acessibilidade/autocomplete do campo permanecem no código. As correções técnicas de consumo e transporte não foram revertidas.

O novo estudo está em [Pesquisa de design](../../PESQUISA-DESIGN-SOLAR-10-10-2026.md).
